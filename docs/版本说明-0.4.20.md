# 0.4.20 测试构建

构建日期：2026-09-11。用于验证详情图片上传后无法插入的修复，真实卖家页面仍需验收。

## 本次修复

- 详情图片上传后，通过关联回执核验自动选中的图片；相册尚未刷新或文件名被截断时，也可继续插入。
- 插入前要求选中池只有一张身份已核验且加载完成的图片；插入后核验预览中的实际图片身份、顺序及原有内容。
- 上传或插入结果不确定时，停止后续图片操作和整段详情自动重试，并阻止保存。
- 报告分别记录文字已写入和图文详情完整，避免图片缺失被误报为成功。
- 没有可关联上传回执时，保留原始图片字节校验。
- 旧编辑器兜底路径无法核验图片身份时，明确报告图片未确定并拦截保存，不再仅凭写入的链接数量报告图片成功。
- 连续插入图片时，等待重新打开的选择器加载完成；上传前遇到失效的 iframe 引用会有限次数重新获取，避免第二张图片偶发中断。

## 验证与限制

- 166 项自动化测试通过，其中 48 项为隔离 Chrome DOM 测试；连续两张详情图的重复复现也通过。图片上传和回执使用隔离模拟页面验证。
- 独立规范与规格审查均为 0 项剩余发现；审查发现的旧编辑器保存拦截遗漏已修复。
- 未执行真实店铺上传、保存及重开验收。跨域选择器及编辑器生成的额外派生图片 URL 仍需现场验证。
- 跨次运行的持久化回执复用不属于此次修复，连续重新运行仍可能重复上传已处理图片。
- SKU 映射、视频、发货时间及已有用户配置不属于此次修改范围。

## 测试步骤

1. 保留旧版与已有报告，解压本版并使用启动器的预览功能。
2. 核对详情图片是否完整、顺序是否正确，同时检查 SKU 图片、价格、库存和重量。
3. 若报告提示图片结果未确定或详情未完成，先核对卖家页面与报告，再决定下一步，避免连续重试上传。
4. 反馈运行日志和对应页面截图；确认预览结果后再进行真实保存验收。

发行包不包含店铺配置、素材或登录数据，升级不覆盖已有本地配置及浏览器 Profile。
