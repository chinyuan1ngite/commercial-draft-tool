# 0.4.18 测试构建

构建日期：2026-09-10。用于继续验证本轮 Code Review 修复，不代表真实卖家页面已通过完整验收。

## 本次修复

- 按命名维度填写销售规格并校验 SKU 组合，避免二维规格计数串行。
- 属性仅以实际提交值确认，排除搜索文本和重复回显。
- 重量按 SKU 身份匹配，保留已采集重量，缺重使用配置值或 1000g。
- 意外确认框改为有界取消，不自动同意丢弃或覆盖操作。
- SKU 图片错误按事务记录；安全可恢复的错误允许继续，未知上传或提交结果阻止保存。
- 图片选择、回显和草稿重开按 SKU 与内容身份核验，避免同名前缀旧图、残留选择和数量变化造成假成功。

## 已知限制

- 平台若生成缩略图、压缩图或转码图，其字节可能不同于原图，当前内容校验会报告未确认。原始素材到平台派生图的可靠关联仍待真实页面证据，不会放宽哈希校验或猜测图片。
- 真实店铺完整保存及重开未完成验收；独立的可见详情编辑器问题未在本轮修复。
- 发货时间等平台必填配置仍需操作者提供；程序不绕过页面校验。视频功能继续暂缓。
- 测试证据来自自动化回归及隔离浏览器页面，不能等同于真实店铺验收。

## 使用范围

先使用预览模式核对规格、各 SKU 价格、库存、重量、图片及可见详情。遇到未决图片事务时先检查卖家页面，不直接重复运行上传。程序仍只保存草稿，不正式上架。

升级不覆盖已有本地运行配置、商品或浏览器 Profile；发行包不包含店铺配置及登录数据。
