# 0.4.22 测试构建

构建日期：2026-09-11。

## 本次修复

- 采集浏览器使用独立端口及已有买家登录配置，避免复用卖家预览的默认端口。
- 在新的采集标签页打开商品，避免恢复的旧标签页通过“是否离开”确认反复阻挡导航。
- 原生提示框重试耗尽或导航未成功时，给出受控失败结果；启动采集浏览器失败时提示检查 Chrome 和配置占用。
- 继续取消普通提示或确认，不自动接受未知确认；采集完成后清理本次创建的采集浏览器。

## 使用与验证范围

全量 172 项测试通过（含 53 项隔离 Chrome DOM 测试）；规范审查与规格审查均无问题。

使用本版启动器重新采集；若买家采集窗口要求登录，请在该窗口完成登录。原有买家配置目录保持不变。

隔离 Chrome 中，持续出现的离开确认已复现与用户日志相同的异常链，采集新标签页修复后可取得目标内容。日志未记录原始提示框类型，因此该复现不能证明现场一定是离开确认。

此版本未执行真实店铺商品上传、草稿保存或发布，详情图片真实页面验收仍与本次采集导航修复分开记录。旧版压缩包和已有配置保留。
