# 1688 自动草稿工具操作说明

## 使用边界

工具只负责采集、数据校验、填写卖家页面和保存草稿。正式上架必须由人工进入卖家后台审核后操作。程序内置正式发布拦截，不会代替审核人点击发布。

## 首次使用

1. 双击 `Commercial1688DraftTool.exe`；源码版双击 `launcher.bat`。
2. 确认界面显示“Chrome：已检测”。未检测时先安装 Chrome。
3. 点击“编辑…”，填写店铺配置。类目默认取当前商品采集到的源叶子类目；只有需要改发其他类目时才填写或捕获目标类目。
4. 保存配置后，先采集一个测试商品，再执行“数据校验”和“预览填充”。
5. 检查预览页面及输出报告，确认类目、店铺、物流和属性映射正确后，才使用“保存草稿”。

如需覆盖商品源类目，可点击“捕获目标类目”：在卖家浏览器中人工选择最终叶子类目并点击“确认类目/继续完善”，工具会读取 `catId` 和类目名称，弹窗确认后才写入运行配置。该操作不会填写商品、上传素材或保存草稿。

## 配置字段

| 字段 | 填写要求 |
|---|---|
| 叶子类目 ID | 卖家发布页最终叶子类目的数字 ID，不填写类目名称代替 |
| 类目名称 | 便于人工核对的名称 |
| 店铺识别文本 | 必填；用于阻止登录错店铺，须为发布页稳定可见的唯一文本 |
| 发货地址匹配文本 | 可选；填写后必须匹配卖家后台已有地址 |
| 运费模板名称 | 可选；填写后必须匹配卖家后台已有模板 |
| 发货承诺 | 可选；填写后必须匹配页面实际选项，例如 `48小时发货` |
| 包裹重量 | 可选统一值；留空时只使用能可靠映射到 SKU 的源件重，不再猜测默认重量；填写时必须是正整数 |
| SKU 图片 | 默认采集并尝试按 SKU 行填写；可在配置窗口关闭采集或填写。缺图默认告警，勾选必填策略后会阻止保存 |
| 卖家 Profile 目录 | 每个卖家店铺必须独立，不要与买家 Profile 共用 |
| 草稿输出目录 | 保存运行报告、截图、台账和运行素材 |

类目属性规则仍保存在 `settings.local.json` 的 `category_rules.by_category.<类目ID>` 中。源商品已采集到的属性会自动按目标页面标签填充，例如“材质：塑料/塑胶”，不需要再次人工确认并配置同名规则。只有源页面确实没有的必填属性，或需要有意覆盖源值时，才配置 `labels`/`properties`；“是否IP授权”在卖家页面明确提示无授权应选择“否”时会采用该安全默认值，其他缺失值不会猜测。

上述地址、运费模板和发货承诺留空时，工具不会填写或核验对应值，也不会主动阻断。重量留空时只使用能可靠映射的源件重；没有可靠源值时保持为空。源商品存在多个不同 SKU 价格时，工具自动选择“按产品规格报价”并填写每个 SKU 的独立价格；价格统一时仍使用按产品数量报价。平台页面若将某字段设为当前类目的必填项，平台校验仍会阻止保存草稿；此时按运行报告补充配置后重试。

## 标准流程

### 1. 采集商品

在“采集链接”输入完整的 1688 商品详情链接，点击“采集商品”。首次运行会打开买家浏览器，登录或验证码由操作者处理。成功后启动器自动选择生成的 `product.json`。

采集只接受页面结构化商品图库和结构化 SKU 图片。SKU 图片按源 SKU ID 关联，缺少 ID 时仅使用唯一规格组合兜底；页面没有行级图片控件时会在报告中标记为不支持，不会按页面顺序猜测。页面没有可信图库、图片下载失败或采集结果不完整时会阻断，需人工处理数据源。

### 1.1 捕获目标类目

点击“捕获目标类目”，在卖家 Profile 对应的浏览器中选择目标叶子类目并点击“确认类目/继续完善”。工具只读取页面证据，不会自动替你选择类目。确认弹窗中的类目名称和 `catId` 后才写入 `settings.local.json`；若 URL、隐藏字段或页面源码中的 ID 冲突，工具会拒绝写入并生成 `category-capture.json` 供排查。

### 2. 数据校验

点击“数据校验”。退出码为 0 才能继续。常见阻断包括：

- 目标类目等必要配置缺失或只有空格
- 标题过长
- 价格、库存或已填写的重量非法
- SKU 维度重复或数据不一致
- 主图或详情图不足
- 素材越过当前商品的 `assets` / `detail-assets` 目录

### 3. 预览填充

点击“预览填充”。程序会打开可见浏览器并填写页面，但不保存草稿。核对：

- 当前店铺身份
- 最终叶子类目
- 标题和主图
- SKU 规格、价格、库存、单品货号
- SKU 图片是否已按行回显；若页面不支持行级图片控件，报告会明确记录 `unsupported_mapping`
- 必填属性及详情内容
- 发货地址、运费模板、发货承诺，以及已配置或能可靠映射的 SKU 件重

预览任务结束后会保留浏览器页面，方便人工检查；预览不会保存草稿。只有点击“保存草稿”并完成重新打开核验后，草稿才会出现在草稿箱。

### 4. 保存草稿

点击“保存草稿”并确认。程序保存后会进入草稿列表，再重新打开本次草稿核验全部关键字段。只有重新核验通过才显示成功。

幂等键为“店铺识别文本 + 源 offer_id”：已有台账时更新原草稿；没有台账但发现同标题历史草稿时会阻断，不会自动删除或覆盖历史草稿。

### 5. 人工审核上架

操作员在卖家后台打开已保存草稿，对照源商品、合规要求和运行报告完成审核。确认无误后由有权限的人员手动正式发布。

## 运行结果

每次执行生成独立目录：

```text
drafts\<offer_id>\<日期时间-随机ID>\
  quality-gate.json
  runtime-config.json
  runtime-product.json
  report.json
  page.html
  page.png
```

退出码：

| 退出码 | 含义 |
|---:|---|
| 0 | 校验或操作完成 |
| 1 | 输入、配置或采集失败 |
| 2 | 登录等待被中止、浏览器被关闭，或采集页面被风控阻断 |
| 3 | 卖家页面关键控件缺失 |
| 4 | 数据质量、安全校验或重新打开核验失败 |
| 5 | 同一卖家 Profile 已被另一个任务占用 |

## 故障处理

- `Chrome：未检测`：安装 Google Chrome 稳定版后重启启动器。
- `seller_login_timeout`：登录等待超过命令行配置的超时时间；图形启动器默认不限时，确认没有误关浏览器后重试。
- `seller_browser_closed_during_login`：登录等待期间浏览器被关闭；重新运行任务即可，已完成的登录会保存在卖家 Profile 中。
- `blocked_store_identity_mismatch`：停止操作，核对当前卖家账号和店铺识别文本。
- `blocked_existing_same_title_draft`：人工核对历史草稿和本地台账，不要直接改标题绕过。
- `blocked_ledger_draft_not_found`：台账记录与当前店铺不一致，先由管理员核对备份和店铺账号。
- `blocked_profile_in_use`：关闭使用同一卖家 Profile 的其他任务后重试。
- `draft_save_not_verified`：草稿可能已保存但核验未通过；先在后台人工检查，不要立即重复运行。
- 页面结构变化或控件缺失：保留该次 `report.json`、`page.html` 和 `page.png`，停止自动保存并提交维护。

任何情况下都不要删除 `draft-ledger.sqlite3` 来绕过重复草稿保护。
