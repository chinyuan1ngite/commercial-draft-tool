# 0.4.23 测试构建

构建日期：2026-09-11。

## 本次修复

- 修复详情选图器切换“相册”或搜索图片后重建 iframe，程序却继续操作旧 frame 的问题。
- 修复已经显示文字组件，但第一张详情图在上传前出现 `ContextLostError`，导致全部详情图片为 0 的问题。
- 每次可能重建选图器文档的操作后重新定位当前 iframe，再继续查找、上传和插入。
- 仅在上传前恢复丢失的 frame；一旦上传或插入可能已经发生，仍停止自动重试并阻止不可靠的草稿保存。

## 现场证据

全量 174 项测试通过，其中包括 55 项隔离 Chrome 测试。

本次读取到的最近两次预览报告一致：9 张源详情图片已成功整理为 4 张长图，但第一张在上传前失败，错误为 `ContextLostError`，最终请求 4 张、插入 0 张、预览 0 张。截图中只出现文字卡片正是该结果。

隔离 Chrome 回归分别模拟切换相册和搜索时替换 iframe。修复前均稳定得到“文字成功、图片 0”，修复后均完成一次上传、一次插入，并从可见详情预览读回正确图片。

此构建不会正式发布商品。真实店铺页面的最终填充结果仍需使用本版重新执行“预览填充”核对。
