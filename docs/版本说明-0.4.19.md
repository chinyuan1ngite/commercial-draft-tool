# 0.4.19 测试构建

构建日期：2026-09-10。用于验证 SKU 图片上传回执修复，不代表真实卖家页面已完成验收。

## 本次修复

- 上传前验证本地文件摘要，使用临时唯一文件名关联本次上传请求与成功回执，不改动原始素材。
- 使用关联回执中的平台图片 ID、原图和缩略图 URL 核验平台处理后的图片，避免压缩后的字节差异阻断正确图片。
- 上传后核验自动加入的唯一选中图片，再执行插入；错图、多选或未知结果仍阻止提交与保存。
- 同一次运行内，相同内容的 SKU 图片可复用已确认回执，不按不同文件名重复上传。
- 相册候选检索有界等待；SKU 图片事务阻断时，报告明确说明后续详情和重量步骤尚未开始。

## 验证与限制

- 154 项自动化测试通过，其中 39 项为隔离 Chrome DOM 测试。上传请求与回执在本地模拟，未向真实店铺上传。
- Code Review：Standards 无确定问题；Spec 仍有跨次运行幂等性未完成项。回执只在单次配置过程中复用，重新运行可能重复上传平台处理后的图片。
- 真实跨域图片选择器的回执捕获、完整 SKU 与详情流程、保存后重开仍需现场验收。
- 无回执及直接文件上传路径仍要求原始内容校验，不猜测派生图 URL。
- 本次解决已知的 SKU 图片阻断原因，不等于已证明真实详情编辑器无独立故障。任务 06/07 不标记完成。
- 视频功能继续暂缓；发货时间等必填配置仍由操作者提供。
