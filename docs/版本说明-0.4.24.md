# 0.4.24 测试构建

构建日期：2026-09-11。

## 本次修复

- 修复打开详情选图器时，平台先创建 `about:blank` iframe、随后切换到跨域图片管理器，程序过早把空白文档当成可用选图器的问题。
- 等到相册、上传、待插入区和确认按钮都出现在当前 iframe 后，才开始清理待插入区、搜索、上传和插图。
- 在上传或插入尚未产生副作用时继续恢复丢失的 frame；一旦副作用可能已经发生，仍停止自动重试并阻止不可靠的草稿保存。

## 复现与验证

0.4.23 的同源 iframe 替换测试没有覆盖平台实际的跨域切换，因此会产生误判。本版新增双源 HTTP 回归：父页面由 `localhost` 提供，图片管理器由 `127.0.0.1` 提供；点击详情图片后先进入空白文档，再延迟切换到第二个源。

在 0.4.23 基线上，该用例稳定得到与现场一致的结果：文字已保存、图片请求 1 张、插入 0 张、预览 0 张，并在准备阶段抛出 `ContextLostError`。修复后同一用例连续两次通过，全部 15 个详情图片浏览器用例也通过。

此构建不会正式发布商品。真实店铺页面的最终填充结果仍需使用本版重新执行“预览填充”核对。
