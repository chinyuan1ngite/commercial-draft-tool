# 0.4.21 测试构建

构建日期：2026-09-11。

## 本次定位与修复

用户提供的两次运行记录均显示：“属性值申请”弹窗仍覆盖页面，详情文本组件未打开，因此没有进入详情图片上传。弹窗只有“取消”和“提交申请”，原有清理逻辑只识别关闭按钮。取消该弹窗的隔离对照恢复了文字及图片插入。

- 识别该属性申请弹窗，在继续页面操作前点击其唯一可用的“取消”按钮。
- 核验弹窗已关闭；找不到可用取消入口或关闭失败时停止流程，并给出明确原因。
- 保留正在使用的图片选择器和详情组件编辑器。
- 跳过隐藏的旧版富文本编辑器，避免把内容写入不可见区域。

## 使用与验证范围

169 项自动化测试通过，其中 51 项为隔离 Chrome DOM 测试；独立规范与规格审查均无剩余发现。

使用本版启动器重新进行预览，检查详情区域的图片是否出现、内容是否完整且顺序正确。报告中可见 `property_application_cancelled:1` 时，表示已取消属性申请弹窗。
