# 环境配置

## 运行环境

- Windows 10/11 64 位。
- Google Chrome 稳定版，建议开启自动更新。
- 可访问 1688 买家详情页和卖家工作台的网络。
- 已获授权的 1688 买家账号与卖家账号。
- 每个店铺使用独立的卖家浏览器 Profile。

发布版 `Commercial1688DraftTool.exe` 不需要安装 Python，也不依赖 Codex。源码版需要 Python 3.11-3.12；首次安装需要网络下载 Python 依赖。

## 发布版目录

将整个发布目录放在普通用户有读取权限的位置，例如：

```text
D:\Tools\Commercial1688DraftTool\
  Commercial1688DraftTool.exe
  README.md
  docs\
```

业务数据不会写进程序目录。首次运行后自动创建：

```text
%LOCALAPPDATA%\Commercial1688DraftTool\
  config\settings.local.json
  products\
  profiles\buyer\
  profiles\seller\
  drafts\
  logs\
```

可以在启动前设置环境变量 `DRAFT_TOOL_HOME`，将完整运行目录迁移到指定位置：

```powershell
[Environment]::SetEnvironmentVariable(
  "DRAFT_TOOL_HOME",
  "D:\CommercialDraftData",
  "User"
)
```

修改后重新登录 Windows 或重启资源管理器再启动程序。不要将它指向原脚本的 `data` 或浏览器 Profile。

## 源码版安装

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

安装完成后双击 `launcher.bat`。脚本会创建项目专用 `.venv`，不会修改系统 Python 包。

## Chrome 与账号

1. 安装或更新 Chrome。
2. 在启动器中执行一次“采集商品”，在打开的买家浏览器内登录买家账号。
3. 执行一次“预览填充”，在打开的卖家浏览器内登录目标卖家账号。
4. 登录、验证码和风控验证必须人工完成。
5. 买家与卖家 Profile 不得使用同一目录；不同卖家店铺也不得共用 Profile。

浏览器 Profile 包含登录会话，禁止放进 Git、网盘共享目录、安装包或工单附件。

## 备份与迁移

程序完全退出且 Chrome Profile 不再占用后，备份以下内容：

- `config\settings.local.json`
- `drafts\draft-ledger.sqlite3`
- `products\` 中仍需使用的商品目录
- 必要时备份 `profiles\seller\`，并按账号凭据管理要求加密保存

升级程序通常只需替换 EXE 和说明文档，不要覆盖 `%LOCALAPPDATA%` 下的数据目录。
