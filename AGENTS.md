# Agent Instructions

## Agent skills

### Issue tracker

GitHub Issues track active task status after the private remote is available; `.scratch/` retains durable specs and historical evidence. Before creating, fetching, updating, or reviewing either form, read [the tracker workflow](docs/agents/issue-tracker.md).

### Triage labels

This repo uses the five default triage labels. Before assigning or changing a triage label, read [the label mapping](docs/agents/triage-labels.md).

### Domain docs

This is a single-context repo. Before exploring or changing domain behavior, read [the domain documentation rules](docs/agents/domain.md).

### Architecture and handover

Before changing product/SKU/report persistence or a cross-module workflow, read [the current architecture](docs/architecture.md) and [data contracts](docs/data-model.md).

Before preparing a release, adding a platform, or resuming maintenance from an unfamiliar state, read [the handover checklist](docs/handover.md) and [compatibility status](docs/compatibility.md).

Before triage, dependency upgrades, release packaging, or rollback, read [the maintenance guide](docs/maintenance.md).
