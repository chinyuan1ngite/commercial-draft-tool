# Agent Instructions

## Agent skills

### Issue tracker

Issues and specs use local Markdown under `.scratch/`. Before creating, fetching, updating, or reviewing a ticket or spec, read [the tracker workflow](docs/agents/issue-tracker.md).

### Triage labels

This repo uses the five default triage labels. Before assigning or changing a triage label, read [the label mapping](docs/agents/triage-labels.md).

### Domain docs

This is a single-context repo. Before exploring or changing domain behavior, read [the domain documentation rules](docs/agents/domain.md).
